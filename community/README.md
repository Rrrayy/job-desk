# 社区面经

这里放的是**真实发生过的面试记录**，用于回答两个问题：

1. 这家公司这个岗位，到底会问什么？
2. 我上次答成那样，下次该怎么改？

不是题库、不是「面试宝典」、不是引流素材。写进来的是自己的真实回答和真实教训。

## 怎么用

**在应用里用（推荐）**：求职工作台 → 复盘 → `[面经]` → 「导入社区题库」→ 选一个 json。
导入的面经带「社区导入」角标，题目会进你的复习队列，但不会算进你自己的战绩统计。

**直接看**：打开任意 `*.json`。每道题都有 `text`（问了什么）、`myAnswer`（当时怎么答的）、
`nextTime`（下次怎么改）—— 第三个字段是重点，前两个只是上下文。

## 贡献

1. 面完就写，趁热。隔一天就只剩「问了几个八股」这种没用的记忆了；
2. 照着 `SCHEMA.md` 建文件 + 更新 `_index.json`；
3. `cd app && npm run validate:community` 必须通过（它会检查格式、id 唯一、长度、**脱敏**）；
4. 提交 PR，PR 模板里会让你确认「已经脱敏」；
5. 被人指出带了私人信息，请立刻改，不要辩解 —— 这种东西删了 commit 也还在。

## 三条不欢迎的内容

- **广告与引流**：内推码、公众号、课程、简历代改。
- **别人的隐私**：HR 姓名、面试官姓名、手机号、内部系统名。
- **虚构经历**：编的面经会误导下一个照着准备的人，比没有更糟。
