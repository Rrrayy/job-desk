# v0.5.0 · 可靠地基

> 发布日期：2026-10-21 ｜ 上一个版本：[v0.4.1](RELEASE-NOTES-v0.4.1.md) ｜ 完整变更：[CHANGELOG.md](../CHANGELOG.md)

**一句话**：这一版不加新视图，只把「数据能不能安心放进去」做扎实 ——
**删错了能找回、导入不再吃掉这一周、破 5 MB 上限、一千条也不卡**，顺手让看板卡片会提醒你上次聊到哪。

---

## 🗄️ 存储不再只有一个 localStorage

以前全部数据压在 localStorage 里，两个硬伤：**容量 5 MB 封顶**，而且**满了只会静默报错**。

现在读写统一走 `StorageBackend` 接口，自动选后端：

| 打开方式 | 用哪个后端 | 为什么 |
| :--- | :--- | :--- |
| 双击 `index.html`（`file://`） | localStorage | 主场景，**不去试探 IndexedDB**，多重试一次只拖慢首屏 |
| 放到网页上（`http(s)`） | IndexedDB 优先 | 容量按磁盘百分比算，不再是 5 MB |

设置页会**如实告诉你现在用的是哪个后端**，IndexedDB 下还显示真实用量与配额。
写入失败通过 `onAsyncWriteError` 上抛，不再静默吞掉。

> 没有引入 Dexie。自写了约 60 行原生 IDB —— 当前只需要一个 kv store，
> 而「单文件、零外部运行时依赖」是这个项目的核心承诺，不该为 3 KB 便利破坏它。

## 🗑️ 回收站：删掉的 30 天内能找回

- 删除投递改为**软删除**：进回收站留 30 天，**第 27 天提醒**一次，到期自动清理。
- 面试与沟通记录跟着一起留，恢复后绑定完整，不用手工补。
- 设置页可以**恢复 / 再留 7 天 / 永久删除**，也能一键清空（二次确认）。
- 撤销（`⌘Z`）与回收站是两套东西：撤销管「刚刚手滑」，回收站管「这几天后悔了」。

实现上只在 `App` 构造 `api.db` 时做**一次过滤**。40 多个消费点逐处判 `deletedAt` 必然漏一个，
那样漏掉的那个地方就会显示一条「已经删了」的投递。

## 🔀 导入：从「整库覆盖」改为「增量合并」

这是本版最该修的一个坑：**拿一周前的备份补一条记录，这一周记的全没了。**

现在只补缺：

- 新增的公司 / 投递 / 面试 / 沟通记录合并进来，**已有的一律不动**
- 去重键 = 公司名（忽略空白与大小写）+ 岗位 + 投递日期，**不做模糊匹配**
- 两边都有但值不同 → 逐条列出差异（本地 / 备份两列并排）让你裁决，**默认保留本地**
- **受保护字段**（简历版本 / 优先级）无论选哪边都保留本地值，面板上明写
- 同一份备份连导两次，第二次显示「全部已存在」，不产生任何重复

导入是唯一允许「整库快照回滚」的操作 —— 因为它本身就是整库级的。

## 📦 便携包导出

一键导出 zip：`index.html`（应用本体）+ `data.json` + `使用说明.txt` + `SHA256SUMS`。

场景是「发给同学看看」「换台电脑直接打开」。以前只有 JSON，对方拿到还得先找程序。

- 应用本体从当前文档**重建**（取内联 style 与 module script），不 `fetch(location)` ——
  `file://` 下 fetch 被拦，dev 下取回的是未构建的 HTML
- 自己写的 ZIP（store 模式、不压缩）：应用 HTML 本身已压过一遍，再 deflate 只省约 5%
- 固定时间戳 + 固定条目顺序，**同一份数据打两次哈希一致**，校验和才有意义
- 导出 JSON 仍然保留：只想备份的话，不该被迫下一个 zip

## 🗒️ 看板卡片直接露出最新记录

不用点开详情，卡片上就有一行**你自己写的最新一条**（随手记 / 沟通 / 催问），类型带小标签
（随手记暖色、沟通蓝色），一行截断、悬停看全文。

同步引擎和示例数据写的系统流水带 `auto` 标记，**不占**这个位置 ——
卡片预览是提醒「上次聊到哪了」，不是回放系统行为。

## ⚡ 长列表窗口化

列表超过 150 行时只渲染视口内的行（上下各多渲染 8 行），滚动用 rAF 节流，表头 sticky 贴顶。

实测 1000 条只渲染 15 行。自己实现（约 80 行纯函数 + 一个 hook）而不是引 `react-window`：
这里只需要「给定行高算区间」，第三方组件的内部行为进不了单测。

顺带修了一个真实缺陷：滚动条拖到底回弹时 `scrollTop` 会超出内容高度，
区间可能算出 `start > end`，让表格塌成 0 行。
