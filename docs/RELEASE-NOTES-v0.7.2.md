# v0.7.2 — 同步确认面板：解析模板 + 人工指定状态

发布日期：2026-10-21 · tag `v0.7.2` · commit `4635049`

主题：**告诉用户「复制什么才能解析好」，并让确认合并不止勾选、还能亲手改。**
起因是用户反馈 v0.7.1 后解析仍不理想，且确认面板只有勾选、没有修改入口。

## 新增

### 1. 同步粘贴解析模板

同步面板第一步新增「不确定复制什么？看这里」折叠块，按平台给出**真机复制样板**：

- BOSS 直聘：卡片形态（招聘者头部那一种）与列表页各一例
- 实习僧 / 牛客：详情页样式
- 猎聘：列表 + 详情
- 自定义通道：通用复制说明

每例标注「照这个样子复制，解析成功率最高」。

### 2. 确认合并时人工指定状态

暂存区行（状态读不出来 / 缺岗位名 / 多条候选）在第三步直接出现状态下拉：

- 选中即按「新增」写入，不再只能进暂存区绕一圈
- 该行标注「✍️ 你手动指定状态：X（按新增写入，不进暂存区）」
- 警告里追加一条，说明状态来源是人工指定而不是解析

## 内部

- 引擎零改动：人工修改是 UI 层把 staged 行就地升级为 `kind:'new'` + `manuallyResolved` 标志，
  复用既有 apply 通道；新增 2 项引擎回归测试锁定该语义。
- 体积 531→544 KB（+13 KB，模板文案 + 状态选择器 + 样式），越过 WARN（540）未动红线（560）。
- 测试：411 项 / 28 文件全绿。
