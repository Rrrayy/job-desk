# 页面抓取扩展（可选）

> 这个扩展**不是必需品**。不装它也能用：在招聘平台的列表页 `Ctrl+A` → `Ctrl+C` → 回到工作台 `Ctrl+V`，
> 走的是完全相同的解析路径。扩展只是把「整页复制」这一步做得干净一点，少带一堆导航文字。

## 它做什么

1. 你在 BOSS / 实习僧 / 牛客的**投递列表页**点扩展图标；
2. 它把当前页面上**已经渲染出来的**卡片读成一段纯文本（一行一个字段，卡片之间空一行）；
3. 复制到剪贴板，格式是一段 JSON 信封：

```json
{
  "format": "job-desk/capture@1",
  "url": "https://www.zhipin.com/web/chat/index",
  "title": "BOSS直聘",
  "capturedAt": "2025-03-12T02:20:11.000Z",
  "text": "字节跳动\n抖音前端开发实习生\n北京 · 海淀区\n250-300元/天\n沟通中\n3月12日 10:20\n\n美团\n…"
}
```

4. 你回到工作台，点顶栏「⇅ 同步」→ `Ctrl+V` → 解析。

## 它明确不做的事

| 不做 | 原因 |
| --- | --- |
| 不发任何网络请求 | 产品的核心承诺是「数据不出本机」。扩展里没有 `fetch` / `XMLHttpRequest` / `sendBeacon`，`npm run check:no-network` 会扫这一条 |
| 不申请任何域名权限 | 只用 `activeTab`（你点图标那一刻才获得当前页的临时权限）+ `scripting`（注入一次脚本）。没有 `host_permissions`，装的时候不会提示「读取你在所有网站上的数据」 |
| 不自动翻页 / 不滚动 / 不点按钮 | 那会替你做你没做的操作，也更容易被平台判定为异常行为 |
| 不读 cookie / localStorage / 登录态 | 只读 `document.body` 里你已经能看见的文字 |
| 不在后台常驻 | 没有 service worker，popup 关掉就结束 |

## 安装（Chrome / Edge，开发者模式）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）；
2. 右上角打开「开发者模式」；
3. 点「加载已解压的扩展程序」，选中这个 `extension/` 目录；
4. 打开招聘平台的投递列表页，点扩展图标 → 「抓取本页并复制」。

## 抓不到怎么办

按顺序试：

1. **先用手动复制**：平台列表页 `Ctrl+A` / `Ctrl+C`，这条路径永远可用，也不依赖扩展；
2. 确认你停在**列表页**而不是单个职位详情页（详情页只有一条记录，抓了也没意义）；
3. 平台改版会让选择器失效。`selectors.json` 里列出了每个平台当前用的选择器，
   `content.js` 顶部的 `SELECTORS` 是实际生效的那份（扩展不能读同包 JSON，否则要 `fetch`，见上文「不做的事」）。
   改选择器时两处一起改，并把 `version` 加一。

> 关于「为什么有两份选择器」：这是刻意的重复。扩展里读一个打包进自身的 JSON 只能靠 `fetch`，
> 而这条产品线不允许出现任何 `fetch`（哪怕是本地文件），
> 否则静态检查就再也拦不住真正的网络调用了。权衡后选择「重复一份表 + README 写清楚」。

## 被平台判定异常的风险

扩展做的事等价于「你自己全选复制」，但你**仍然**要对使用行为负责：
不要高频刷、不要批量抓取，一天一两次足够。这一段和应用内的风险确认门是同一段话，
不是免责声明套话 —— 账号是你在用。
